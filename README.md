# CockroachDB

CockroachDB is the distributed, PostgreSQL-compatible SQL database built by Cockroach Labs. It is a product, not a separate API provider: the CockroachDB Cloud API is profiled in the cockroach-labs repository, which is canonical. Consolidated 2026-10-13, approved by Kin Lane.

Canonical profile: [api-evangelist/cockroach-labs](https://github.com/api-evangelist/cockroach-labs) — https://apis.io/providers/cockroach-labs/
